# Удаленные файловые системы в BlackBox Scheduler

Теперь BlackBox Scheduler поддерживает работу с удаленными файловыми системами NFS и SMB для мониторинга конфигурационных файлов на удаленных серверах.

## Конфигурация

### 1. Настройка .env файла

Скопируйте `.env.example` в `.env` и настройте параметры:

```bash
cp .env.example .env
```

### 2. Выбор типа файловой системы

Измените параметр `FILE_SERVER_TYPE`:
- `nfs` - для сетевой файловой системы NFS
- `smb` - для сетевой файловой системы SMB/CIFS

### 3. Параметры NFS

```env
FILE_SERVER_TYPE=nfs
NFS_SERVER=192.168.50.149
NFS_SHARE_PATH=/srv/share
NFS_MOUNT_POINT=/mnt/nfs
```

### 4. Параметры SMB/CIFS

```env
FILE_SERVER_TYPE=smb
SMB_SERVER=192.168.50.149
SMB_SHARE_NAME=share
SMB_MOUNT_POINT=/mnt/smb
SMB_USERNAME=guest
SMB_PASSWORD=
SMB_DOMAIN=WORKGROUP
```

## Запуск

### С Docker Compose

1. Убедитесь, что `.env` файл настроен правильно
2. Запустите сервис:

```bash
docker-compose up scheduler
```

### Вручную

1. Соберите проект:
```bash
cd scheduler
go build -o scheduler .
```

2. Настройте переменные окружения
3. Запустите:
```bash
./scheduler
```

## Как это работает

1. При запуске программа читает настройки из `.env`
2. Автоматически монтирует удаленную файловую систему в указанную точку
3. Проверяет доступность удаленной папки
4. Начинает мониторинг файлов в удаленной директории
5. Обрабатывает изменения и сохраняет версии в базу данных

## Требования к удаленным серверам

### Для NFS
- Сервер NFS должен быть доступен из контейнера
- Экспортированная директория должна иметь права на чтение
- Рекомендуется использовать NFSv4 для лучшей производительности

### Для SMB/CIFS
- Сервер SMB должен быть доступен из контейнера
- Пользователь должен иметь права на чтение файлов
- Поддерживаются SMB 2.0 и выше

## Диагностика

При запуске программа выводит подробные логи:
- Успешное монтирование файловой системы
- Ошибки подключения
- Найденные конфигурационные файлы
- Результаты обработки

## Безопасность

- Рекомендуется использовать dedicated пользователя с минимальными правами
- Для SMB используйте сложные пароли
- В продакшене настройте firewall для ограничения доступа

## Устранение неисправностей

### Проблемы с монтированием NFS
- Проверьте доступность сервера: `ping $NFS_SERVER`
- Убедитесь, что NFS сервис запущен на сервере
- Проверьте экспортированные директории: `showmount -e $NFS_SERVER`

### Проблемы с монтированием SMB
- Проверьте доступность сервера: `ping $SMB_SERVER`
- Убедитесь, что шара доступна: `smbclient //$SMB_SERVER/$SMB_SHARE_NAME`
- Проверьте учетные данные

### Права доступа
- Убедитесь, что контейнер имеет права на монтирование ФС (privileged: true)
- Проверьте права на директорию точки монтирования
